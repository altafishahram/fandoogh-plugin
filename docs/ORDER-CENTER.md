# مرکز سفارشات فندوق

شناسه ماژول: `order-center`

این ماژول از پنل فندق فعال می‌شود و برای کارکرد به WooCommerce نیاز دارد. سفارش‌ها فقط از API رسمی WooCommerce خوانده می‌شوند و با HPOS سازگار هستند.

## امکانات

- KPI امروز، ۷ روز و ۳۰ روز اخیر
- لیست سفارش‌ها با جست‌وجو، فیلتر وضعیت و صفحه‌بندی ۲۰تایی
- جزئیات محصولات، مشتری، آدرس‌ها، پرداخت، ارسال و خلاصه مالی
- تغییر وضعیت با `manage_woocommerce` و Nonce
- ثبت یادداشت داخلی
- نمایش محدود و امن Order Meta
- هوک توسعه `fandoogh_order_center_extension_area`

درآمد وضعیت‌های `failed` و `cancelled` را شامل نمی‌شود و مبلغ Refund از مبلغ سفارش کم می‌شود. برای فعال‌سازی، از «فندق ← مدیریت CRM» کارت مرکز سفارشات را روشن کنید؛ پس از فعال‌سازی، منوی مرکز سفارشات در منوی اصلی مدیریت وردپرس نمایش داده می‌شود.
