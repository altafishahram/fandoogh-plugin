# تغییرات

## 1.0.0 — 2026-08-18

- تکمیل Description، Video، FAQ و FAQ Schema.
- یکپارچه‌سازی Reviews با تأیید مدیر، امتیاز و کش میانگین.
- تکمیل Customers و Projects به‌صورت مستقل با taxonomy، shortcode و Dynamic Tag.
- افزودن سئوی محصول (FAQ اختصاصی و پاسخ تک‌سؤالی) با Schema امن.
- افزودن ماشین حساب قیمت با قیمت‌های ثابت، اعتبارسنجی سمت سرور و افزودن به سبد.
- افزودن ماژول مستقل مرکز سفارشات WooCommerce با HPOS، KPI، فیلتر، صفحه جزئیات، تغییر وضعیت، یادداشت داخلی و Order Meta امن.
- افزودن کارت داشبورد، فعال/غیرفعال‌سازی وابسته به WooCommerce و منوی مستقل مرکز سفارشات.
- رفع وابستگی Asset ماشین‌حساب، پاک‌سازی رجیستری Assetها و یکدست‌سازی کلاس‌های Frontend ماشین‌حساب با پیشوند `fa-`.
- حذف فایل و پوشه‌های توسعه‌ای بدون استفاده از بسته افزونه.
- حذف SEO داخلی برای جلوگیری از تداخل با Rank Math و Yoast.
- تکمیل لایه‌های Repository، Service و Renderer.
- افزودن nonce، capability، Rate Limit، Migration و Cleanup ارتباط‌ها.
- سازگاری با WordPress 7.0، WooCommerce 10.9 و Elementor 4.1.
- طراحی پنل RTL، Responsive و AJAX.
- افزودن سیاست حفظ داده و حذف انتخابی در Uninstall.
