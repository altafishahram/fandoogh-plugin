# Fandoogh Framework

نسخه پایدار 1.0.0 فریم‌ورک فندق برای WordPress، WooCommerce و Elementor.

## نیازمندی‌ها

- WordPress 6.8 یا جدیدتر
- PHP 8.2 یا جدیدتر
- WooCommerce فعال
- Elementor برای استفاده از Dynamic Tagها (اختیاری)

## نصب

1. فایل `fandoogh-1.0.0.zip` را از بخش افزونه‌ها بارگذاری کنید.
2. افزونه را فعال کنید.
3. از منوی «فندق ← ماژول‌ها» قابلیت‌های لازم را فعال کنید.

راهنمای کامل کاربر در [docs/USER-GUIDE.md](docs/USER-GUIDE.md) و مستندات توسعه در [docs/DEVELOPER.md](docs/DEVELOPER.md) قرار دارد.

## سیاست داده‌ها

غیرفعال‌سازی افزونه هیچ داده‌ای را حذف نمی‌کند. در حذف افزونه نیز داده‌ها به‌صورت پیش‌فرض باقی می‌مانند؛ حذف کامل فقط با فعال‌کردن گزینه مربوط در «فندق ← تنظیمات» انجام می‌شود. فایل‌های رسانه‌ای و دسته‌های محصول ووکامرس حذف نمی‌شوند.

## تغییرات 1.0.0

- ماژول‌های توضیحات، ویدیو، FAQ، نظرات، مشتریان، پروژه‌ها و مرکز سفارشات WooCommerce
- ماژول سئوی محصول (FAQ محصول و پاسخ تک‌سؤالی) و ماشین حساب قیمت
- شورت‌کدها و Dynamic Tagهای المنتور
- FAQ Schema و سیستم نظرات نیازمند تأیید مدیر
- داشبورد فارسی، RTL، Responsive و AJAX
- مدیر پوسته پنل با Static Dynamic CSS، Preview زنده، Preset و Dark Mode
- مهاجرت داده، پاک‌سازی ارتباط‌ها و Uninstall انتخابی

## مرکز سفارشات

مرکز سفارشات از «فندق ← مدیریت CRM» فعال می‌شود و فهرست، KPI، جزئیات، وضعیت و یادداشت داخلی سفارش‌های WooCommerce را با پشتیبانی HPOS ارائه می‌کند.
