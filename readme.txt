فریم‌ورک حرفه‌ای فندق برای مدیریت محتوای دسته‌های محصول، سئوی محصول، نظرات، مشتریان، پروژه‌ها، ماشین حساب قیمت و مرکز سفارشات ووکامرس.

== Description ==

شامل ماژول‌های توضیحات، ویدیو، FAQ، سئوی محصول، نظرات، مشتریان و پروژه‌ها همراه با شورت‌کد و Dynamic Tag المنتور؛ همچنین ماشین حساب قیمت و مرکز سفارشات WooCommerce با پشتیبانی HPOS.

== Installation ==

1. بسته افزونه را نصب و فعال کنید.
2. وارد فندق ← ماژول‌ها شوید.
3. ماژول‌های موردنیاز را فعال کنید.
