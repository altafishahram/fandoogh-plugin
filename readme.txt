فریم‌ورک حرفه‌ای فندق برای مدیریت محتوای دسته‌های محصول، نظرات، مشتریان و پروژه‌ها.

== Description ==

شامل ماژول‌های توضیحات، ویدیو، FAQ، نظرات، مشتریان و پروژه‌ها همراه با شورت‌کد و Dynamic Tag المنتور.

== Installation ==

1. بسته افزونه را نصب و فعال کنید.
2. وارد فندق ← ماژول‌ها شوید.
3. ماژول‌های موردنیاز را فعال کنید.
